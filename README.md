# TrackSmart AI

TrackSmart AI is a Django-based Student Management and AI-powered Student Behavior Detection System.

## Features

- Admin, Teacher and Student roles
- Role-based authentication and dashboards
- Student and teacher management
- Attendance management
- Marks management
- Report cards
- Notice management
- Manual behavior logging
- AI-based student behavior detection
- REST APIs with session-based authentication

## AI Behavior Detection

The system uses a CNN-based MobileNetV2 model with TensorFlow/Keras to classify student behavior into:

- Attentive
- Irrelevant
- Sleeping
- Using_Mobile
